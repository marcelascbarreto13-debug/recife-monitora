# Recife Monitora — Análise de Dados

Projeto desenvolvido na disciplina de Projetos 5 do curso de Gestão de Tecnologia da Informação da CESAR School.

## Sobre o projeto

O projeto tem como objetivo realizar o entendimento, preparação e análise dos dados relacionados ao programa Recife Monitora.

**Base sintética**

Os dados utilizados nesta etapa são simulados e não representam resultados reais da Secretaria de Saúde do Recife.

## Estrutura do projeto

- `dados/` — bases utilizadas no projeto
- `notebooks/` — notebooks de exploração e análise
- `src/` — módulos e funções reutilizáveis
- `requirements.txt` — dependências do projeto

## Etapas

1. Entendimento dos dados
2. Preparação e limpeza
3. Análise exploratória (EDA)
4. Visualização
5. Modelagem
6. Reexecução do pipeline com dados atualizados

## Reprodutibilidade

O projeto será estruturado para permitir a substituição da fonte de dados sem necessidade de reescrever todo o pipeline.
